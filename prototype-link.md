# Prototype link

Prototype Chặng 4 là prototype HTML chạy độc lập, không cần API hoặc build tool.

Mở file [`prototype/index.html`](./prototype/index.html) bằng trình duyệt.

## Cách chạy

1. Tải repository về máy hoặc mở thư mục repo trong file explorer.
2. Mở `prototype/index.html` bằng Chrome, Edge hoặc trình duyệt tương đương.
3. Giữ nguyên common context và cùng task khi thử A, B và C.
4. Dùng `Reset prototype` trước khi chuyển sang một lượt test mới.

Tester có thể tự thao tác cả ba option; canned AI output được ghi rõ trong giao diện và không cần facilitator giải thích.
